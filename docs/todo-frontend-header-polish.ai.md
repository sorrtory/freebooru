# Header and catalog polish contract

- [x] Header order is collection, Overview, Tags, fluid search, Files, Upload, Settings.
- [x] Storage management is reached from Settings, not collection navigation.
- [x] Header search opens a collection-aware completion panel while typing and labels usage-ranked tags Popular.
- [x] Starter character values are Konata, Kagami, Tsukasa, and Miyuki; `original_character` is not generated.
- [x] Starter storage is represented as an imported, required `storage` tag.
- [x] Tag summaries expose groups and open Files search when clicked.
- [x] File previews use fewer, larger columns on wide screens.
- [x] Collection creation uses a quiet background.
- [x] Multivalue options stay bounded and do not cover editor actions.
- [x] Clicking an open assignment card surface, including its expanded body, closes it without discarding the draft.
- [x] Deterministic demanded assignments are applied automatically and disappear from Suggested.
