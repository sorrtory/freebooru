### Plugins

Allows to run native code from the frontend.

- [opener plugin](https://github.com/tauri-apps/plugins-workspace/blob/v2/plugins/opener) - Open files and URLs using their default application.
- [shell plugin](https://github.com/tauri-apps/plugins-workspace/blob/v2/plugins/shell) - Access the system shell. Allows you to spawn child processes and manage files and URLs using their default application.
