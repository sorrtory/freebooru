# Freebooru

Freebooru is an app inspired by the UX of these awesome ideas

- booru style tagging
- rclone easy storage access
- obsidian flat zettelkasten model

> The goal is to keep your file collections organized and eassy to access, even if it is stored inside different storage providers

## Insipiration

- [tagspaces](https://github.com/tagspaces/tagspaces) - handy s3 based tagging system
- [hydrus](https://github.com/hydrusnetwork/hydrus) - sofisticated booru style tagging
